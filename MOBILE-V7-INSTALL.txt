McGriff's Mobile v7.0 — VERIFIED PATCH

This patch was made directly from the uploaded "mobile-redesign (7)" source.

FIXES
1. Equipment Rent button: corrected a JavaScript error caused by calling the nonexistent equipmentStatus() function. It now calls statusFor() and opens the checkout workflow.
2. Full-screen signature: Capture Signature opens the full-screen signing pad. The bottom now has only Reset and Done, as requested.
3. Signature email: Code.gs now accepts the signedContract action and embeds the signature as an inline image in the email.
4. Cache/version verification: mobile files and service worker are bumped to v7.0. A red v7.0 badge appears on the login and home screens.

1. Close the installed app completely.

3. Verify the red "v7.0" badge appears.
