McGriff's Rental Manager — Mobile v7.1

WHAT CHANGED
1. The main GitHub Pages link automatically sends phones and tablets to mobile.html.
2. Add ?desktop=1 to the main URL when you intentionally want the desktop portal on a phone/tablet.
3. Fixed the mobile Equipment > Rent button. It was calling a nonexistent equipmentStatus() function; it now uses the app's real statusFor() function.
4. Full-screen signing pad now shows only Reset and Done at the bottom.
5. Signed-contract emails now support the mobile action and embed the customer's captured signature inline.
6. Updated cache/version numbers so phones load the new files.

GITHUB FILES
Upload the CONTENTS of this folder to the root of the mobile-redesign branch, replacing matching files. At minimum replace:
- index.html
- mobile.html
- mobile.js
- mobile.css
- service-worker.js

APPS SCRIPT

Then Deploy > Manage deployments > Edit > New version > Deploy.
Keep the same /exec URL.
